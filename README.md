# 紙箱檔案館 / Paper Box Archive

一個零依賴的瀏覽器互動怪談。訪客受邀整理一隻機器貓遺留的檔案，卻慢慢發現系統已經開始替訪客建立檔案。

直接以瀏覽器開啟 `index.html` 即可遊玩。第一版為本機原型，尚未發布。

## 操作

閱讀左側檔案，找出有矛盾的紀錄；新檔案會在足夠的證詞後解鎖。終端支援 `help`、`files`、`status`、`where`、`inspect`、`reconcile`、`leave` 與 `clear`。

## 第一版路徑

1. 從燈泡與夜班紀錄找出 04:20 的矛盾，解鎖維護申請單。
2. 對照訪客索引和維護紀錄，解鎖不在場證明。
3. 讀完歸還紀錄後，可直接 `leave`，或先 `reconcile` 再離館，得到不同結局。

## 第二輪：記憶

瀏覽器會以 `localStorage` 保存閱讀進度、回訪次數與離館後的選擇。結局出現後輸入 `keep` 或 `discard`，第八號「室溫紀錄」會在往後的回訪中保留不同內容。

## 第三輪：時間異常

終端新增 `time` 指令。每日本機時間 04:20–04:24，清單會短暫出現第九號「時鐘校正單」；若在窗口內讀取，檔案會被保存在後續回訪中。其餘時間只會留下夜班預告與錯過窗口的痕跡。

## 第四輪：證詞牆

「把證詞釘起來」是獨立的推理牆。選三張彼此能證明同一件事的證詞後提交；正確推論會永久保存在本機狀態，並補上一句關於出口真正用途的證詞。
